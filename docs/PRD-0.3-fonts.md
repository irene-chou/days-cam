## 2. 範圍

### 2.1 這次要做

1. 字型清單換成 21 套繁中字型：蘋方（內建）、開源 3 套、系統可下載 17 套（§4.1）
2. 樣式分頁的字型格子只放能直接用的字型，最後一格「更多字型」（FR-10.2′）
3. 「更多字型」全螢幕清單：依風格分段、下載、套用、刪除、字型授權（FR-16）
4. 開源字型的下載、驗證、儲存、註冊；系統字型的下載與每次啟動的比對（§5、§6）
5. 舊設定檔的字型轉換（§4.3）
6. 面板與工具列調整（2026-10-05 人類追加，§5.3）：比例鍵 1:1 外框縮小；「格式」兩個子分頁合併成一頁；「格式」與「天數規則」合併成「內容」分頁；面板加高讓「內容」分頁不需捲動

### 2.2 非目標

- 字重選擇、使用者匯入自己的字型、App 內購字型
- 背景下載（App 退到背景後下載中斷，回來顯示可重試）
- 遠端字型清單（新增字型要發新版 App）
- 0.2 §2.2 的其他非目標照舊；「打包字型檔」改為本版的「下載字型檔」，App 本身仍不打包

### 4.2 開源字型資產

| 項目 | 規格 |
|---|---|
| 檔案 | 上游官方 release 的**原檔**，不子集化、不改名（A-1）。思源宋體取 Bold 單一字重 |
| 下載點 | 公開 repo `irene-chou/dayscam-fonts` 的固定 tag；主要網址 jsDelivr，備援 GitHub raw（A-2） |
| 完整性 | App 內寫死每個檔案的大小與 SHA-256；下載後比對，不符就刪檔並視為失敗 |
| 存放 | `Application Support/Fonts/<fontID>.<副檔名>`，設為不備份到 iCloud（可重新下載） |
| 註冊 | 下載完成、以及每次啟動時，用 `CTFontManagerRegisterFontURLs`（`.process` 範圍）註冊 |
| 授權 | 每套附 OFL 1.1 全文；粉圓另附 Apache-2.0 全文（漢字衍生自 Kosugi Maru） |

### 4.3 舊檔轉換

- 0.2 設定檔的 `fontID` 是 10 種英文字型之一 → 轉成 `pingFang`（§4.1 的未知 ID 規則自然涵蓋），下次寫入時存成新值。
- 其他樣式欄位（顏色、外框、陰影、字級）不變。
- 0.1 格式的舊檔照 0.2 §4.3 轉換，字型一律落在 `pingFang`。

### 4.4 字型狀態

**存檔**：`UserDefaults` 的 `downloadedSystemFontIDs`（`[String]`）記下使用者在 App 內下載成功過的系統字型。iOS 重開後無法直接查出哪些系統字型已在手機上，只有會觸發下載的比對介面能讓它重新可用（調查報告 §A），所以要自己記。開源字型以 `Application Support/Fonts/` 內檔案是否存在為準，不另存清單。

**執行期狀態**（不存檔）：

| 狀態 | 意義 |
|---|---|
| `available` | 可以直接畫：蘋方；已註冊的開源字型；已比對成功的系統字型 |
| `notDownloaded` | 手機上沒有 |
| `preparing` | 啟動後正在註冊或比對（手機上有，尚未能畫） |
| `downloading(progress)` | 下載中，0～1 |
| `failed(reason)` | 下載或驗證失敗；`reason` 至少分「沒網路」與「其他」 |

## 6. 拍攝與烘焙（0.2 §6 的增補）

| # | 需求 |
|---|---|
| FR-5.14 | **觀景窗與照片用同一個字型解析結果**：渲染時由同一個函式把 `fontID` 解析成實際字型；字型不是 `available` 時，兩邊都解析成蘋方（FR-16.14）。不得出現觀景窗是 A、照片是 B。量字寬（自動縮小）也必須用同一個解析結果。觀景窗若有快取，快取鍵須包含解析後的字型，狀態改變時一定重畫 |
| FR-5.15 | 啟動時：開源字型逐一註冊；`downloadedSystemFontIDs` 內的系統字型逐一比對，目前設定檔用的優先。比對過程只要出現「將開始下載」或「下載中」狀態（表示已被系統清掉，不論是否附帶下載量），立即取消、從 `downloadedSystemFontIDs` 移除並視為 `notDownloaded`，**不得自動下載**。目前設定檔的字型為 `preparing` 時**快門暫時不能按**（顯示為停用），比對完成即恢復；每套字型從它自己開始比對起算，超過 3 秒仍未完成，**取消該次比對**（之後的回呼一律忽略），該字型變 `failed(.other)`（可在清單重試），照 FR-16.14 改用蘋方並恢復快門 |

## 9. 測試需求

| 模組 | 要求 |
|---|---|
| 字型清單 | **必須**有單元測試：21 種 `fontID` 的順序、分段、來源與 §4.1 一致；10 種舊 ID 與任意未知字串解碼為 `pingFang` 且設定檔不丟 |

| 預覽圖 | 21 張都存在且非空白 |
