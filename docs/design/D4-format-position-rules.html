第 2 版

面板空間：打開時觀景窗縮小到 80%

面板打開時，觀景窗等比縮小到 80% 寬並置中（照片比例不變、整張仍看得到），面板多出約 90pt 高。樣式分頁的選項列、天數規則的三列都能完整放下，不用捲動。收起面板時觀景窗彈回滿版。D-2、D-3 已同步改成這個行為。

回覆

「第 0 天／第 1 天」為什麼不見

是空間不足：天數規則的第三列（起算規則）被面板底部裁掉了。改成觀景窗縮小後，三列都顯示得出來。

建議試這條路徑：
  1. 格式 → 顯示內容：打開「日期」「名稱」，再關掉「天數」
  2. 格式 → 天數格式：勾年、月、週、天各種組合，看觀景窗的文字
  3. 切到「位置」分頁後，在觀景窗上拖曳疊字，或點九宮格對齊
  4. 天數規則：改起始日、切換「第 1 天／第 0 天」
  5. 頂部切到「日期戳」看天數關閉時各分頁的樣子
格式

第二層：顯示內容｜天數格式

顯示內容：天數、日期、名稱三個開關並排。天數和日期只剩一個開著時，那個開關變灰並顯示「至少要顯示天數或日期其中一項」（FR-2.4）。天數格式：「從」最大單位、「到」最小單位，兩排文字選項，「到」只列出合法的單位（FR-2.8）；右邊是「年改成歲」開關，只有「從」選年時能開（FR-2.9）。天數關閉時整區變灰。

第 5 版

天數格式：任意勾選單位

「年 月 週 天」勾哪些就顯示哪些，任何組合都可以，只剩一個時那格鎖住。算法固定：先算滿幾年，再從週年日算滿幾個月，剩下的天數拆成週和天；沒勾的單位不拆。例如只勾年和天，會顯示「1 年 150 天」（過了週年日的第幾天）。

規則

起算 +1、「第 N 天」與「又」

起算規則的 +1：沒勾年也沒勾月時才套用（同 0.1）。「第 N 天」：只勾天時用序數，其他情況用「N 天」（同 0.1）。「又」：勾兩個單位、且不含年時用「又」（「61 週又 3 天」「14 個月又 5 天」「14 個月又 3 週」），其他一律空格（「1 年 2 個月」「1 年 5 個月 3 週 2 天」）。這樣 0.1 所有組合的輸出都不變。

第 2 版

位置：直接拖曳疊字

只有在「位置」分頁時，觀景窗上的疊字會出現虛線框，按住就能拖到任何地方，不會超出照片 4% 邊距；其他分頁或面板收起時都不能拖，避免調樣式、拍照時誤觸。分頁裡保留九宮格當快速對齊，拖過之後顯示「自訂位置」。位置以照片寬高的百分比儲存，換比例、換解析度都會落在同一個相對位置。這會解除 0.1「不提供自由拖曳」的限制（FR-4.5）。

天數規則

名稱、起始日、起算規則三列

名稱直接在列上編輯（最多 20 字）；起始日點開 iOS 日期選擇器，最晚只能選今天（§7.2）；起算規則用兩段的分段控制「第 1 天｜第 0 天」。天數關閉時隱藏起始日和起算規則，只留名稱並說明原因（FR-3.7）。

即時

所有變更即時寫回設定檔

沒有儲存鍵。改什麼，觀景窗就立即變什麼；切換設定檔後各自保留自己的設定。
