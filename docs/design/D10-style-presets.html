文字樣式改成固定組合

把「字型／顏色／外框／陰影／字級」五個各自調整的子分頁，換成一列命名樣式。選一款就是一組好看的字型＋外框＋陰影；之後只能改顏色、底框和字級。這是 Instagram 限時動態的切法，也是研究裡使用者驗證最多的模式。

已定（2026-11-04）：IG 模式（樣式鎖字型、外框、陰影；開放顏色、底框三態、字級）・先不改版面（疊字仍是單行「日期 名稱 第 N 天」）・8～12 款一列橫滑・點樣式自動下載字型。
已選定（人類 2026-11-06）：樣式列用方案乙（膠囊名稱）・十款全留・底框鈕要・手寫用辰宇落雁體。

1. 「樣式」分頁：現況 → 方案甲／乙

面板是 FR-19／FR-20.10 共用的「文字樣式」面板，約 4 成高，從檢視頁與相機取景窗都開得到。寬度以 375pt 為準，樣式列可左右滑；下方顏色、字級沿用現有元件。

取捨：甲多 20pt 高，但「字幕／海報／便條」這三款差在底框，只有縮圖看得出來；乙在 375pt 能同時露出 5～6 款，甲露出 4.5 款。兩案都保留現有的 18 色＋彩虹圓＋最近，字級滑桿照舊。
人類 2026-11-06 選定乙：省高度、一次露出更多款；底框差異由底框鈕與膠囊底色（字幕半透明、海報實心、便條白底）表達。

2. 十款樣式（＋兩款候補）

字級以 375pt 寬取景窗的 100% 畫（約 20pt）。切換背景看每一款在亮、暗、花背景上是否都站得住。每款下方寫的是對應到 OverlayStyle 現有欄位的值；沒有新欄位。外框色與陰影色一律「自動」或「跟隨文字色」，所以改顏色時整組會一起變、不會打架。

3. 底框鈕「A」：三態循環

放在彩虹圓那一列的右端。每按一次換一態：樣式原本的外框 → 實心底框 → 半透明底框 → 回到原本。「原本」可能是無（經典）、描邊（描邊、可愛）或已經是底框（字幕、海報）；底框與描邊互斥，這跟現有 OverlayOutline 單一欄位一致。底框色一律自動對比色，不另選。
框的形狀由樣式決定（人類 2026-11-06 選 A）：方角＝海報、描邊、雜誌；圓角 8＝經典、字幕、便條、復古；膠囊（全圓）＝可愛、霓虹、手寫。A 鈕仍是三態，鈕的外形跟著形狀畫。

要不要這顆鈕？有：IG／TikTok 都有，使用者熟；十款裡的「字幕」就是「經典＋第三態」，可以少一款。沒有：面板更乾淨，底框差異全靠樣式列承擔，十款都要保留。人類 2026-11-06 選定有；「字幕」仍保留為獨立一款。

4. 其他行為

情境行為
選樣式把樣式的字型、字重、外框、外框透明度、描邊寬、底框內距、陰影參數整組寫進紀錄的 style；保留使用者目前的文字顏色與字級（IG 行為：換字型不會把你調好的顏色洗掉）。例外：樣式帶「預設色」（可愛、霓虹、復古）且目前顏色是上一款的預設色或白色時，換成新預設色。
改顏色只改 textColor。描邊、底框走自動對比色，發光跟隨文字色，所以整組一起變。
字型還沒下載點了立刻選中，取景窗先用蘋方畫，縮圖右上「↓」變進度環；下載完自動換（沿用 FR-16.6「套回開始下載時的紀錄」）。下載失敗 toast「字型下載失敗，先用蘋方顯示」，樣式維持選中。
選中判定紀錄的 style 在「字型、字重、外框、描邊寬、底框內距、陰影幾何」上等於某款 → 該款亮；顏色、字級、底框三態不影響判定（跟現在 shadowPreset 的做法一樣）。
舊紀錄的樣式不等於任何一款樣式列最後多一張「自訂」卡，畫的就是現在這組，亮著；沒有編輯入口。點任一款就覆蓋；只有這張卡還在用時「自訂」才出現。這是 0.2 自由調整留下的唯一出口。
「更多字型」清單從樣式分頁拿掉。字型授權頁要有新入口（紀錄編輯頁或關於頁），由 Lead 另開卡。

5. 決定紀錄

  • 樣式列：乙（膠囊名稱）。
  • 樣式：十款全留——經典、字幕、海報、描邊、雜誌、手寫、便條、可愛、霓虹、復古；文楷、極簡不做。
  • 底框鈕：有。
  • 手寫：辰宇落雁體（細）。
